My website has been through many versions. Until recently it was even completely offline for a while.
I had to self-host it on a Raspberry Pi 4 because Synapse[^1] needed to use the domain name as well.
Then I had the port forwarding off for a while because I wasn't ready to start it up.
Now it's back to running on GitHub Pages[^2] again.

I wasn't happy with any of the previous versions of the website I'd produced.
They had quite poor layouts and designs, and I didn't feel like they expressed myself correctly.
I also tried experimenting with Next.js[^3], but I decided I wanted to stick to a single minimalistic site that also included my blog.
So I've gone back to using the static site generator Hugo[^4] and I set up a theme that suits me best.

I don't think I'll be changing my site to a new version anytime soon---this design actually feels "right".
It's like the final iteration of all of my previous versions.

Identity is a tricky thing. You want to do your best work and make something that expresses yourself, but you can't even be sure what yourself is.
My identity has changed a lot, but I'm finally feeling like I'm reaching the point of understanding myself more. 

{{< bear >}}Care for yourself and yourself will care for you.{{< /bear >}}

There's a hell of a lot that I can write about now. Have a Happy New Year---Maddie.
